# Profile media

## Visual system

The profile uses four domain colors and icons everywhere: robotics (amber, arm), industrial automation (blue, PLC module), embedded systems (green, chip), and AI and LLM tools (violet, node graph). The banner, project cards, and legend all share the same 24-by-24 icon paths.

## Banner

`hero-arm.webp` is an original Three.js render. A three-joint arm solves inverse kinematics to move a part between two stations. Around it are a PLC rack with status LEDs, a microcontroller on a circuit-board floor, and a rotating LLM node graph linked to the arm and the PLC. The capture is one full loop (13.8 seconds at 15 frames per second), rendered at 1920 by 600 and downscaled to 1280 by 400. `hero-arm-still.png` is one frame from the same loop; the README shows it when the browser requests reduced motion.

To regenerate it, run `python tools/banner/server.py 8124` and open `http://127.0.0.1:8124/index.html?save=1&dist=13.4&ty=1.75&ox=0.17`. The page writes PNG frames to `tools/banner/frames/`. Then encode them:

```sh
ffmpeg -framerate 15 -i tools/banner/frames/f%04d.png -vf "scale=1280:400:flags=lanczos" -c:v libwebp_anim -quality 75 -compression_level 6 -loop 0 assets/hero-arm.webp
```

## Other graphics

`stack-isometric.svg` is an original isometric drawing of six technology layers. Its CSS animation lifts the layers apart and sends a highlight upward, and it is disabled for reduced motion.

`button-linkedin.svg`, `button-email.svg`, and `button-github.svg` are original static contact buttons.
