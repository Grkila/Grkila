# Profile media

## Visual system

The project cards use four domain colors and icons: robotics (amber, arm), industrial automation (blue, PLC module), embedded systems (green, chip), and AI and LLM tools (violet, node graph).

## Light and dark themes

The README serves every graphic in two themes through `<picture>` sources keyed on `prefers-color-scheme`, which follows the viewer's GitHub theme. `hero-arm-light.webp` is the same scene rendered as a daytime lab (`tools/blender/09_daylight.py`), with saturated neon and no bloom so the name stays readable on a bright wall. `cards/light/` and `stack-isometric-light.svg` are made by `python tools/theme_light.py`, which swaps the dark palette for GitHub's light palette and leaves embedded screenshots untouched. The banner also has a reduced-motion still in each theme.

## Banner

`hero-arm.webp` is a Blender 5.2 EEVEE render of an engineering lab, built through the Blender MCP add-on ([ahujasid/blender-mcp](https://github.com/ahujasid/blender-mcp)). A Franka Panda arm picks up a sponge (the thesis slip tests used sponges) and places it across the bench, then brings it back, so the loop is seamless. Its joint angles come from inverse kinematics on the official Panda kinematics, and the fingers close on the sponge. Around it, with nothing intersecting: a neon name sign, an HMI trend monitor and an LLM tool console, a gripper-controller PCB, a wall control cabinet, a Husarion Panther UGV, and a PLC training stand. The loop is 13.4 seconds at 15 frames per second, rendered at 1920 by 600, with a soft bloom added afterwards. `hero-arm-still.jpg` is one frame for reduced-motion viewers.

Every built object is textured: Poly Haven textures with box projection for the room, cabinet, stand panel, rails and sponge; generated image textures for the screens and the PCB; and procedural noise for roughness and bump on the robots, modules, and plastics.

`tools/blender/` holds the pipeline in run order. Set `BANNER_DIR` to a working folder that contains the converted `glb/` meshes and `poses.json`, and `SIEMENS_MODELS` to the folder with the Siemens OBJ exports. Run `00_*` with system Python. Run the rest inside Blender through the MCP add-on's `execute_code`, then render with `blender -b banner.blend -a`. Finally, apply `08_bloom.py` and encode:

```sh
ffmpeg -framerate 15 -i bloom/f%04d.png -c:v libwebp_anim -quality 90 -compression_level 6 -loop 0 assets/hero-arm.webp
```

## Project cards

Most cards are SVGs generated by `python tools/gen_cards.py .` and given light copies by `python tools/theme_light.py`. The SCADA, SilverOne, Modbus, and Intro Path Discovery cards are animated drawings: the SCADA HMI uses the app's real tags and alarm, SilverOne follows the architecture in its README, and Intro Path Discovery is a concept. The robot manipulator card embeds its [LabVIEW front panel](https://github.com/Grkila/Serial-Two-Joint-Robot-Manipulator-Simulation-and-Control/blob/main/docs/images/front_panel_overview.jpeg) (`manipulator-panel.jpg`).

Three cards are animated WebP, built by `tools/raster_cards.py`, which renders the same card frame at 2x and composites the animation into it:

| Card | Animation |
| --- | --- |
| Adaptive gripper | The project's own [sponge slip test](https://github.com/Grkila/Adaptive-Gripper-with-Micro-Vibration-Based-Slip-Detection/blob/main/docs/images/gifs/sponge_speedup.gif), about six seconds of it. |
| GridLab | The 3D Novi Sad scene from GridLab's presentation (`web/src/presentation/City.tsx`), captured frame by frame with `tools/gridlab/capture.tsx`. Each car runs whole laps of its street circuit, and every third car stops to charge, so the loop is seamless. Map data © OpenStreetMap contributors (ODbL). |
| Airlock HIL testbench | A Blender render (`tools/blender/10_airlock_card.py`) of a rover passing through the three-zone airlock: gate A opens, the rover waits in the middle zone, gate A closes, gate B opens. Poly Haven CC0 assets: `drackenstein_quarry` HDRI, `aerial_sand` and `box_profile_metal_sheet` textures, `boulder_01` and `circuit_board` models. |

## Other graphics

`stack-isometric.svg` is an original isometric drawing of six technology layers. Its CSS animation lifts the layers apart and sends a highlight upward, and it is disabled for reduced motion.

`button-linkedin.svg`, `button-email.svg`, and `button-github.svg` are original static contact buttons.
